# 🛒 Next.js E-Commerce Platform

A fully responsive **E-Commerce web application** built with **Next.js, TailwindCSS, and Shadcn UI**, providing a smooth and modern shopping experience across all devices.  

## 🚀 Features
- ✅ Fully responsive (mobile, tablet, desktop)  
- 🌙 Dark mode support  
- 🔐 Secure authentication with **NextAuth**  
- 🛍️ Wishlist & Cart with **Context API**  
- 💳 Checkout system (Credit card & Cash on delivery)  
- 🧾 REST API integration (Products, Users, Orders)  
- 🎨 Modern UI with **TailwindCSS** + **Shadcn UI**  
- ☁️ Deployed on **Vercel**  

## 🛠️ Tech Stack
- **Framework:** Next.js  
- **Styling:** TailwindCSS, Shadcn UI  
- **Auth:** NextAuth.js  
- **Forms:** React Hook Form  
- **State Management:** Context API  
- **Deployment:** Vercel
